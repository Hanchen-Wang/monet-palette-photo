# Card examples

These examples demonstrate card structure only. Do not reuse their subjects, palette families, zones, or composition as defaults for another photograph.

- [examples/atmospheric-reflection.json](examples/atmospheric-reflection.json) shows partial source preservation with a reflection-led painted event.
- [examples/distilled-rain.json](examples/distilled-rain.json) shows a no-pixel, M4 distillation using the `sparse_social` profile and Shape Extraction Card.
- [examples/zine-cutout-isolation.json](examples/zine-cutout-isolation.json) shows the stricter two-cutout Zine strategy: one prominent original-pixel anchor with recorded recognition features, one painted carrier, and 30–60% blank paper.
- [examples/comparison-poster.json](examples/comparison-poster.json) shows the default original-over-generated Social Output Card. It controls deterministic layout, not image generation.

Use an example only to understand field relationships. Every real card must be rebuilt from the supplied photograph.
